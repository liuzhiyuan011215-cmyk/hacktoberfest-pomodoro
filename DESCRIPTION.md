# App description (no screenshots)

The page opens on a dark purple background with orange accents. A header shows the app title, "Hacktoberfest Pomodoro + Task Tracker". The main card holds a large circular progress ring with the remaining time (e.g. 25:00) in the center and the current mode (Focus / Break) labeled. Under it are Start/Pause and Reset buttons, plus inputs to change the focus and break lengths. The ring drains as time passes; when a session ends a soft beep plays and the mode switches.

Next to the timer (or below it on narrow screens) is the task panel. You type a task and add it. Each task has a checkbox to mark it done, a delete button, and a way to make it the active task. Every finished focus session adds a pomodoro (🍅) to the active task. A stats area shows how many sessions are complete. Tasks, settings and stats all stay in localStorage, and pressing Space toggles the timer.
